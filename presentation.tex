\begin{frame}{Where are the problems?}
    \begin{itemize}
        \item Package server may go down
        \item Used releases may be yanked for security reasons and not longer available
        \item Packages may be updated by repository mainainers e.g. apt
        \item Packages may not be available for a newer system architecture
        \item Virtualizing a System may become more difficult
        \item Files cannot be read because of propierary file formats
    \end{itemize}
\end{frame}

\begin{frame}{What does this mean?}
    \begin{itemize}
        \item Not only the code and datasets BUT all of their dependencies, compiler versions ...
        \item E.g. compiler optimization bugs in polynomial operations caused wrong results
        \item Have a future reader understand the complete setup
        \item System configs may require deep setup understanding and are hard to reproduce even by the authors
    \end{itemize}
\end{frame}

\begin{frame}{How did it work finally?}
    \begin{itemize}

        \item All dependencies via apt available
    \end{itemize}
\end{frame}

\begin{frame}{How to archive digital work?}
    \begin{itemize}
        \item Pin all versions using commit-shas or lock-files from tools like cargo, uv, npm, maven, nix ...
        \item Package a Docker Image / Docker Compose setup or Virtual Machine Disk Image
        \item If not possible have exact setup description (maybe special hardware is required, FPGAs etc.)
        \item Use tools like \citetitle{reprozip} to help identify and package relevant components through syscall tracing
        \item Where to archive the digital artifacts?
        \item Programs like GitHub Arctic Code Vault help preserve code, but not artifacts
    \end{itemize}
\end{frame}
